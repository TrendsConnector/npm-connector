## How to ask

Pass the exact package name. It is case-sensitive. Scoped names such as @babel/core are valid.

**Good to know:** This is weekly downloads for that package. It is not GitHub stars, and it is not PyPI. Python packages are on the PyPI connector.

## FAQ

**Are package names case-sensitive?**  
Yes. Pass the exact npm name, such as react or @babel/core.

**Does this include Python packages?**  
No. PyPI downloads are on the PyPI connector.

**Is the npm connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.
